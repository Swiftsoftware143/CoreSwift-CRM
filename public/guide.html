Moving Deals Through the Pipeline

To advance an opportunity to the next stage:

  • Drag-and-drop Drag an opportunity card from one stage column to another
  • Change stage dropdown Use the stage selector on the opportunity detail panel

Both actions use:

PATCH /api/opportunities/:id
Authorization: Bearer <token>

{ "stage_id": "uuid-of-next-stage" }

You can also update value, probability, expected close date, and notes in the same request.

Winning & Losing Deals

When a deal reaches a Won or Lost stage, CoreSwift automatically sets the corresponding boolean flags:

  • Won: is_won = true adds value to the "Won Deal Value" dashboard stat
  • Lost: is_lost = true optionally record a lost_reason for analysis
Tip: Track lost reasons to analyze patterns and improve your sales process.

Opportunity Analytics

The dashboard aggregates:

  • Total Deal Value Sum of all open (not won/lost) opportunities
  • Won Deal Value Sum of all won opportunities
  • Pipeline Stage Counts Number of opportunities per stage per pipeline

All computed server-side from opportunities table queries.

Satellite Apps: FunnelSwift, IncentiveSwift, WorkflowSwift, and MissedCall Respondr can push data into CoreSwift via inbound webhooks.

Inbound Webhooks (Receiving Data)

Other apps can send events to CoreSwift using authenticated webhook endpoints. Events are verified with satellite API keys.

POST /ihook/:key_prefix/:event_type
X-Satellite-Key: <full-api-key>
Content-Type: application/json

{ "payload": "data" }

Or the v2 endpoint:

POST /ihook-v2/:key_prefix/:event_type
X-Satellite-Key: <full-api-key>

17 Revenue Forecast

Pipeline Forecast View

The Forecast page shows your projected revenue based on deals in your pipeline. It calculates a weighted pipeline value by multiplying each deal's value by its stage probability.

How It Works

  • Total Pipeline Value — Sum of all deal values across all stages
  • Weighted Pipeline Value — Sum of (deal value × stage probability) for each deal
  • Bar Chart by Stage — Visual breakdown of total deal value per stage, with the won stage highlighted

Interpretation

The weighted pipeline value gives a realistic estimate of expected revenue. For example, if you have $10,000 in the Discovery stage (30% probability) and $15,000 in the Negotiation stage (70% probability), your weighted forecast is $3,000 + $10,500 = $13,500.

18 Activity Timeline

Deal Activity History

Each deal has an activity timeline that records every change made — stage moves, value updates, tag changes, contact links, and notes. This gives full audit trail visibility into how a deal has progressed.

Viewing the Timeline

Open any deal detail view and scroll to the Activity Timeline section. Events are listed in reverse chronological order with timestamps, action descriptions, and the user who performed the action.

Timeline Events

  • Stage Change — Moved from X to Y (with probability change)
  • Value Change — Deal value updated ($500 → $1,000)
  • Contact Linked — Contact associated with the deal
  • Contact Created — New contact auto-created from deal
  • Tag Added/Removed — Tags applied or removed
  • Note Added — Notes on the deal
  • Deal Created — Initial creation event
  • Deal Won/Lost — Deal closed
  • Reminder Set — Follow-up reminder created

API Access

GET /api/v1/deals/{deal_id}/timeline
Authorization: Bearer <token>

This pattern is also available in sister apps (FunnelSwift and IncentiveSwift) for seamless lead-to-deal creation.

Conversion Tracking

When a referred lead completes a purchase, the conversion is tracked automatically:

  1. Checkout Metadata

    The system stores affiliate_id and/or cookie_id in the checkout session metadata.

  2. Webhook Fires

    On successful payment, the Stripe/PayPal webhook fires a conversion event to FunnelSwift.

  3. Commission Recorded

    FunnelSwift records the conversion and attributes commission based on the affiliate's rate.

This is fully automatic. As long as the affiliate link is used at checkout, nothing extra is needed.

Managing Affiliates

Affiliates are managed through the FunnelSwift Admin portal:

  • Affiliate Admin — full CRUD for affiliate products, categories, links, and conversion history
  • Affiliates — add, edit, and manage affiliate partners with commission rates
  • Affiliate Products — configure which products can be promoted and at what commission rate
  • Affiliate Links — create tracking links that pair an affiliate with a specific product

To access, log in to FunnelSwift and navigate to Super Admin → Affiliate Admin.
